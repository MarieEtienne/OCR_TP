# OCR_TP
Assignment for MODE 2026 OCR courses

Welcome to **OCR assignment**! 🎓  

This repository is a collaborative space for students in the **Open Reproducible Resources (OCR) 2026** course to create and share **concise and basic descriptions os their prefered dataset and the statistical methods which can be relevant to analyze those data** as an exercise to practice reproducible science

It’s designed to help you practice **reproducible science skills**, including:  
- Using **Git and GitHub** for version control  
- Writing **Quarto** document for clear, readable documentation  
- Organizing simple **presentation of data**  and **basic mathematical models**.

It will also served as sandbox during the lectures. Therefore the git history might be a bit fuzy. (actually the tree has been cleaned before the project).



## Repository Structure

Student are paired. Each pair choses an ecological dataset which can be used to illustrate one of the following statistical methods
- Lineal modelling
- Factorial analysis
- Partial differential equation 

Each pair choses an personal  dataset theme and devotes to produce a relevant example of how the specific method could be used to build ecological knowledge from a dataset.

Quarto files (`.qmd`) which contains 
- a **short stats/math reminders**  
- data presenation with  **plots, tables, or small example datasets**
- and references ussing markdown format
- **explicit ecological results** obtained thanks to the method of interest

The different works are brought together in a simple website using CI tools to produce high quality colloborative work. As mentionned in the course, addition to the main branch should be achived only though Pull Request and ckecks should be passed before merging into the main branch.
